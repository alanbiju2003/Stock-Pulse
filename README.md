# Stock-Pulse
Stock Data it shows various companies and indexes performance over the years
The application displays stock data obtained from CSV files in a modern web-based visualization with responsive design features. The web app incorporates an attractive navbar together with a dynamic sidebar containing the company listings. An interactive click on a company reveals animated closing price values through Chart.js without forcing page reloads.

Several modern effects improve the UI including glowing buttons together with smooth transitions and the glassmorphism layout design. The data presentation divides information by year to allow simpler analysis of trends through the presentation. Front-end design and data management merge in this application to create an appealing user-friendly interface.
